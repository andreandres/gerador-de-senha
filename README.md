# 🔐 Gerador de Senhas Seguras

Um script simples e eficiente em Python para gerar senhas fortes e aleatórias.

## 📝 Sobre
Este projeto utiliza a biblioteca **`secrets`** do Python (em vez da `random`) para garantir que as senhas sejam criptograficamente seguras. Cada senha gerada contém obrigatoriamente:
- Letras maiúsculas e minúsculas
- Números
- Caracteres especiais

## 🚀 Como rodar o projeto

### Pré-requisitos
Você precisa ter o **Python 3** instalado no seu computador.

📄 Exemplo de Saída

O programa irá gerar e validar 3 senhas automaticamente:

#Exemplos

Senha Validada 1: aB3$kL9@xP

Senha Validada 2: 9#mP2&qL!z

Senha Validada 3: X7@pL$3mQq
